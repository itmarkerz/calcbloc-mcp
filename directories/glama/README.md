# Glama

The server is already listed at https://glama.ai/mcp/servers/itmarkerz/calcbloc-mcp (Glama indexes public GitHub repositories on its own), and its score badge works.

To claim the listing (so Glama shows it as maintained and lets you edit it):

1. [`glama.json`](../../glama.json) is at the repository root with the maintainer's GitHub username (`binumathew`). Add more usernames there if other people maintain the server, then commit and push.
2. Sign in to Glama with that GitHub account, open the listing and use **Claim ownership**. Re-run the claim after any change to `glama.json`.
3. Use the shared listing text in [../README.md](../README.md) for the description and tags.

The awesome-mcp-servers list uses the Glama score badge in its entries; see [../awesome-mcp-servers/entry.md](../awesome-mcp-servers/entry.md). [`glama.json`](glama.json) in this folder is the template.
