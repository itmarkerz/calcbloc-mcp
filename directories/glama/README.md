# Glama

1. Open https://glama.ai/mcp/servers and use **Add Server** with the repository URL `https://github.com/itmarkerz/calcbloc-mcp`.
2. To claim the listing (needed for Glama to show it as installable and to edit it), copy [`glama.json`](glama.json) to the repository root, replace `YOUR_GITHUB_USERNAME` with the GitHub username(s) of the maintainers, commit and push, then run Glama's **Claim ownership** flow. Re-run the claim after any change to `glama.json`.
3. Use the shared listing text in [../README.md](../README.md) for the description and tags.

Glama shows a score badge that the awesome-mcp-servers list uses in its entries; see [../awesome-mcp-servers/entry.md](../awesome-mcp-servers/entry.md).
